Manta Client

A launcher and client mod for Minecraft: Java Edition.

Manta is a desktop launcher plus an in-game client mod for Minecraft: Java Edition (Fabric). It is a free, independent project.

Features

  • Launcher with game profiles and versions
  • Built-in performance and quality-of-life mods, each with its own settings
  • Friends list with online status
  • Parties: invite friends and join servers together
  • Cosmetics such as capes, plus emotes
  • Server quick-join from the main menu

Microsoft sign-in

Manta uses Microsoft sign-in only to authenticate your Minecraft account so you can launch and play the game, the same way the official launcher does. Manta never sees your Microsoft password; sign-in happens on Microsoft's own page. See the Privacy Policy for details.
