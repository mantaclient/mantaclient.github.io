Manta Client

A launcher and client mod for Minecraft: Java Edition.

Manta is a Windows launcher plus an in-game client mod for Minecraft: Java Edition (Fabric). It is a free, independent project.

Screenshots

Features

  • Launcher with game profiles and versions, and a mod browser powered by Modrinth
  • Built-in performance and quality-of-life mods, each with its own settings
  • Friends list with online status, and parties to join servers together
  • Cosmetics (capes and emotes) unlocked through quests
  • Skin manager and editor
  • Instant gameplay clips and a screenshot gallery
  • Player stats, FPS reports and lag diagnosis
  • Server quick-join from the main menu

Microsoft sign-in

Manta uses Microsoft sign-in only to authenticate your Minecraft account so you can launch and play the game, the same way the official launcher does. Sign-in happens on Microsoft's own page and Manta does not read or store your password. See the Privacy Policy for details.
